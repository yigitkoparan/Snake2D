# Snake 2D (Unity)

A classic retro arcade Snake game built in Unity 6. Navigate the grid, eat food to grow longer, and survive as the speed progressively increases.

---

## Features

* **Grid-Based Movement:** Smooth step-by-step movement locked to grid coordinates.
* **Progressive Difficulty:** Snake movement speed increases with every piece of food collected.
* **Smart Food Spawning:** Randomized food placement that actively avoids spawning inside the snake's body.
* **Score Tracking & Arcade UI:** Live score counter and retro-styled Game Over screen with instant keyboard restart.

---

## Controls

| Action | Key(s) |
| :--- | :--- |
| **Move Up** | `W` / `Up Arrow`|
| **Move Down** | `S` / `Down Arrow` |
| **Move Left** | `A` / `Left Arrow`|
| **Move Right** | `D` / `Right Arrow` |
| **Restart Game** | `Spacebar` |
