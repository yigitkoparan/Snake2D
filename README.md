# Snake 2D (Unity)

A classic retro arcade Snake game built in Unity 6. Navigate the grid, eat food to grow longer, and survive as the speed progressively increases[cite: 1, 5].

---

## Features

* **Grid-Based Movement:** Smooth step-by-step movement locked to grid coordinates[cite: 1, 5].
* **Progressive Difficulty:** Snake movement speed increases with every piece of food collected[cite: 5].
* **Smart Food Spawning:** Randomized food placement that actively avoids spawning inside the snake's body[cite: 4].
* **Score Tracking & Arcade UI:** Live score counter and retro-styled Game Over screen with instant keyboard restart[cite: 5, 6].

---

## Controls

| Action | Key(s) |
| :--- | :--- |

| **Move Right** | `D` / `Right Arrow`[cite: 5] |
